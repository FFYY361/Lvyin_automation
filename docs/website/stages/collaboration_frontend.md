# Stage 5 协作前端操作手册

Stage 5 为 Stage 4 的注册、任务认领和正文协作接口增加完整网页，并保留 Stage 3 的
管理员闭环。本阶段不修改数据库和后端 API，不包含 PWA 或生产部署。

## 1. 启动

先启动 PostgreSQL、执行迁移并启动后端：

```powershell
conda activate lvyin
python -m alembic upgrade head
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

开发模式在另一个终端启动前端：

```powershell
cd frontend
pnpm dev
```

打开 `http://127.0.0.1:5173`。构建后也可以由 FastAPI 单进程提供页面：

```powershell
cd frontend
pnpm build
cd ..
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

## 2. 登录和注册

- 管理员登录后进入“批次管理”。
- 普通用户可从登录页进入注册页；注册成功后自动登录并进入“任务中心”。
- 用户名区分大小写、不能包含空白；密码至少八个字符。
- “个人设置”可修改展示名称和密码。展示名称修改不会改变已有比赛署名；密码修改会使
  其他设备的旧会话失效。

## 3. 普通用户任务流程

任务中心从上到下依次显示：

1. “我的任务”：默认显示本人当前开放任务；勾选“显示未开放任务”后也显示关闭或失效任务。
2. “待领取任务”：当前可以领取的任务。

普通用户看不到“全部开放任务”。日期和赛事筛选会同时作用于两个分区。任务卡只显示
比赛信息、状态和认领人，不显示正文状态、版本或更新时间。“我的任务”先排开放任务，
再排未开放任务，各组内按开球日期降序；“待领取任务”也按开球日期降序。

在“待领取任务”点击“领取任务”。领取成功后任务出现在“我的任务”，此时才能进入
比赛页。并发情况下若其他成员先领取，页面会提示原因并刷新列表。释放任务需要二次确认；
释放会清空认领人与署名，但保留已填写正文。

普通用户在批次详情中可以查看所有比赛和认领人，但只有本人任务是可点击链接。直接打开
他人或未认领比赛地址也不会显示正文编辑器。

## 4. 正文编辑和预览

普通用户的署名只读，只编辑纯文本多段正文。点击“保存正文”后版本递增；有未保存内容时
离开页面会提示。若正文版本冲突，必须选择加载服务器版本，或基于最新版本人工合并后再保存，
页面不会静默覆盖。

普通用户可以从批次详情查看管理员最近一次渲染的文章。正文修改后文章会过期，需要管理员
重新渲染，普通用户不能自行执行渲染。

## 5. 管理员协作流程

管理员保留 Stage 3 的批次创建、编辑、渲染和微信草稿功能。任务中心额外在页面底部显示
“全部开放任务”，任务按开球日期降序，可进入任意比赛、把任务转交给启用账号或释放任务。管理员比赛页可同时
修改多作者署名和正文。

“用户管理”只对管理员开放：

- 页面使用单列列表，每个用户独占一行；
- 修改普通用户展示名称；
- 启用或停用普通用户；
- 重置普通用户密码；
- 查看领取任务数。

管理员账号在该页面只读。停用账号或重置密码会使旧会话失效，但不会自动释放任务。

## 6. 验证

```powershell
cd frontend
pnpm typecheck
pnpm test
pnpm build
```

随后回到项目根目录：

```powershell
python -m ruff check backend src test scripts
python -m pytest
python scripts/smoke_website_api.py
```

人工验收至少使用一个管理员和两个普通用户，覆盖并发领取、本人正文保存、越权比赛地址、
管理员转交、文章重新渲染，以及手机宽度下的导航、任务卡和正文编辑。
